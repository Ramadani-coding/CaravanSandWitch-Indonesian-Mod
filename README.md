# Caravan SandWitch — Mod Bahasa Indonesia

Mod terjemahan lengkap Bahasa Indonesia untuk game **Caravan SandWitch** (versi Steam / PC). Menerjemahkan **5.880 baris teks** secara menyeluruh mulai dari dialog cerita, misi, deskripsi item, menu utama, pengaturan, hingga UI antarmuka.

## Fitur Mod
- **Terjemahan Penuh (100%)**: Seluruh 5.880 baris teks di `Game.locres` sudah diterjemahkan ke Bahasa Indonesia yang natural dan mudah dipahami.
- **Nama Karakter & Lore Terjaga**: Nama karakter dan istilah kunci (*Sauge*, *Garance*, *Nèfle*, *Cigalo*, *TARAASK*, *Rose*) tetap dipertahankan agar tidak merusak nuansa cerita.
- **Drop-in Patch (`.pak`)**: Tidak menimpa atau merusak file asli game. Cukup taruh satu file di folder `~mods`, dan hapus kapan saja jika ingin kembali ke Bahasa Inggris.

## Cara Pemasangan

1. Buka halaman **[Releases](https://github.com/Ramadani-coding/CaravanSandWitch-Indonesian-Mod/releases/latest)** dan download file **`pakchunk99-Indonesian_P.pak`**.
2. Buka folder instalasi game **Caravan SandWitch** di Steam:
   - Klik kanan **Caravan SandWitch** di Steam Library -> **Manage** -> **Browse local files**.
   - Masuk ke folder `CaravanSandWitch\Content\Paks\`.
3. Di dalam folder `Paks`, buat folder baru bernama **`~mods`** (perhatikan tanda `~` di depan).
   - Contoh path lengkap: `...\CaravanSandwitch\CaravanSandWitch\Content\Paks\~mods\`
4. Salin/pindahkan file **`pakchunk99-Indonesian_P.pak`** ke dalam folder `~mods` tersebut.
5. Jalankan game seperti biasa. Pastikan bahasa game di Steam/Settings disetel ke **English**, karena mod ini menggantikan resource bahasa Inggris (`en/Game.locres`).

## Menghapus Mod
Cukup hapus file `pakchunk99-Indonesian_P.pak` dari folder `~mods`. Bahasa game akan langsung kembali ke bahasa Inggris semula.

## Kontribusi & Perbaikan Teks
Jika menemukan terjemahan yang kurang pas atau typo di dalam game, kamu bisa membuka **Issues** atau mengajukan **Pull Request** dengan mengedit file sumber di `source/Game_id.json`.
